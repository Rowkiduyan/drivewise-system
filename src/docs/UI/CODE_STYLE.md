# UI Code Standards

## Goal

Write UI code that is easy to understand, easy to maintain, and suitable for student developers.

---

## Priorities

Always prioritize:

- Clean code
- Simple code
- Readable code
- Maintainable code

---

## React

Prefer:

- Functional components
- React hooks
- Tailwind CSS
- Descriptive variable names
- Straightforward React patterns

---

## Components

- Reuse existing components whenever possible.
- Avoid duplicate components.
- Keep components reasonably small.

---

## Avoid

- Over-engineering
- Unnecessary abstractions
- Unnecessary custom hooks
- Unnecessary utility files
- Deeply nested JSX
- Premature optimization

---

## Scope

Unless requested:

- Do not redesign unrelated pages.
- Do not change business logic.
- Do not introduce new UI libraries.
- Do not rename files unnecessarily.
- Do not refactor unrelated code.

Only modify the files needed to complete the requested task.
