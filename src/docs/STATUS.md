Verified: pause on an Active session → `200`; pause with no open session → `400 "No active session found for this delivery"`; resume after pause → `200` with a new session row; resume again while already Active → `409 "This delivery already has an active session"`. Not separately tested: the own-delivery-403 check (same simple equality pattern already verified for Start Trip) and the device-already-active-elsewhere reject on Resume (would need a second truck/device fixture) — deemed low-risk, same call made for Start Trip's remaining guardrail.
